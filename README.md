# Virtual Drum Machine

A browser-based virtual drum machine and sequencer. Customize your sounds and pads, program your own loops, and if you're feeling really spicy, enable Hype Mode.

## System Requirements

- Node.js v24+

## Installation

- Install NPM modules

  ```bash
  npm install
  ```

## Run Development Server

```bash
npm run dev
```

## Run tests

```bash
npm run test
```

## Build For Production

```bash
npm run build
```
